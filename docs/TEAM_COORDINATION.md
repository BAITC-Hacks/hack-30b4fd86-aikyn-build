Каждому отдельный checkout. Не менять одновременно один файл. Базовую версию передать обоим из локальной папки капитана либо после разрешённого push. Текущий удалённый README не заменяет отсутствующий код.

Порядок интеграции: проверить актуальность origin → сохранить локальные изменения → согласовать README с фактической реализацией → принять алгоритм и проверки → повторить PASS → пересоздать submission → проверить diff → локальный commit → явное подтверждение → push.

При проверке 23.09.2026: локальный HEAD 774b35d; origin/main 3260bb9, на один коммит впереди, меняет README. Локальная реализация ещё не закоммичена и не отправлена. Git fetch выполнен; merge/rebase/push не выполнялись. Доступ на чтение подтверждён, право записи этой проверкой не установлено.
