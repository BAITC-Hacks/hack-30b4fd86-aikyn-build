# Demo Contract

Before polishing UI, define one reproducible demo contract.

## Template

**Input:** what the user provides.

**Transformation:** what the AI/agent does.

**Validation:** what must be true for success.

**Persistence:** what state/result must survive if the case requires it.

**Evidence:** what the jury can visibly verify.

**Failure mode:** what the system shows when required data is missing or the run fails.

## Principle

A demo is successful only if the same flow can be repeated without manually repairing the output.
