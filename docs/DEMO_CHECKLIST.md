# Demo Checklist

A demo is ready only when the full flow works end to end.

## Functional

- [ ] Official case requirement is addressed.
- [ ] One clear user flow works without manual repair.
- [ ] Required fields are validated.
- [ ] Errors fail visibly instead of pretending success.
- [ ] Output can be reproduced during the presentation.

## Technical

- [ ] App starts from a clean state.
- [ ] API/model dependency is reachable.
- [ ] No secrets are exposed in frontend or Git.
- [ ] Backup network/runtime path exists.
- [ ] Repository contains the version being demonstrated.

## Presentation

- [ ] Problem explained in one sentence.
- [ ] Why AI/agentic approach is needed is clear.
- [ ] Live demo starts within the first 90 seconds.
- [ ] Architecture can be explained in under 30 seconds.
- [ ] One measurable result is shown.
- [ ] Limitations are stated honestly.
- [ ] Final callout maps directly to judging criteria.
