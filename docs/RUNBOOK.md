# Hackathon Runbook

## Before start

- laptops charged;
- Wi-Fi 5 GHz verified;
- GitHub access verified;
- Codex installed and authenticated;
- official repository cloned;
- backup internet available.

## At case release

1. Read once without coding.
2. Fill CASE_INTAKE.md.
3. Agree on one PASS condition.
4. Choose the smallest demo.
5. Split work.
6. Start implementation with Codex.

## Build order

1. Happy-path end-to-end flow.
2. Required validation.
3. Persistence/evidence if needed.
4. Error handling.
5. UI polish only after the flow works.

## Freeze

Final 90 min: no large architecture changes.
Final 45 min: demo rehearsal and submission only.
