## Как увидеть точные изменения

История Git сохраняет предыдущие версии. Коммит документации можно просмотреть через git show, а изменения отдельных файлов — через git diff между нужными коммитами. Этот список служит пояснением; точный состав изменений определяется diff соответствующего коммита.
